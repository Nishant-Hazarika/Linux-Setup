# Linux-Setup
Personal Arch Linux (Hyprland) configuration for future cases.
Steps for setting up after a fresh install:
  1. Install :
     i. firefox
    ii. waybar (https://github.com/Alexays/Waybar)
   iii. hyprlock
    iv. hyprlauncher
     v. hyprpaper [or hyprquickpaper (https://github.com/iamsurjog/hyprquickpaper)]
    vi. hypridle
   vii. wlogout (https://github.com/ArtsyMacaw/wlogout)
  viii. Sway Notification Centre (https://github.com/ErikReider/SwayNotificationCenter)
    ix. pavucontrol
     x. yay (https://github.com/Jguer/yay)
