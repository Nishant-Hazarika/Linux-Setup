# Linux-Setup
Personal Arch Linux (Hyprland) configuration for future cases.
Steps for setting up after a fresh install. Install these for setting up the basic files :
1. firefox
2. waybar (https://github.com/Alexays/Waybar)
3. hyprlock
4. hyprlauncher
5. hyprpaper [or hyprquickpaper (https://github.com/iamsurjog/hyprquickpaper)]
6. hypridle
7. wlogout (https://github.com/ArtsyMacaw/wlogout)
8. Sway Notification Centre (https://github.com/ErikReider/SwayNotificationCenter)
9. pavucontrol
10. yay (https://github.com/Jguer/yay)
